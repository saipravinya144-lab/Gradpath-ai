# GradPath AI 🎓

**Your personalized career and internship preparation platform.**

GradPath AI helps engineering students build technical skills, explore career paths, prepare for placements, and track their learning progress.

## Features

- **Student Dashboard** — Profile, learning progress, and quiz performance.
- **Core Subjects** — Java, JavaScript, Data Structures and Algorithms (DSA), and DBMS.
- **Career Roadmaps** — Structured learning paths for six roles:
  - Full Stack Developer
  - AI/ML Engineer
  - Android Developer
  - Data Analyst
  - Cybersecurity
  - Cloud/DevOps Engineer
- **Interactive Quizzes** — Test knowledge and review quiz results.
- **Progress Tracking** — Track completed lessons and quiz history.
- **AI Career Mentor** — Career guidance and learning-roadmap suggestions.
- **Career Preparation** — Placement readiness, aptitude, coding interviews, and company preparation.
- **Resume and Interview Preparation**
- **Internship Preparation**

## Tech Stack

- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- Node.js and npm
- MongoDB connection
- Git

### 1. Clone the repository

```bash
git clone https://github.com/saipravinya144-lab/Gradpath-ai.git
cd Gradpath-ai
```

### 2. Start the backend

```bash
cd backend
npm install
```

Configure the required environment variables in a local `.env` file. Then start the backend using the script specified in `backend/package.json`.

### 3. Start the frontend

Open a second terminal from the project root:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite.

**Security:** Never commit API keys, database credentials, or other secrets to GitHub.

## Project Goal

GradPath AI brings technical learning, career roadmaps, quizzes, and placement preparation together in one platform to help engineering students prepare for their careers.
