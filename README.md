# GradPath AI 🎓

**Your personalized career and internship preparation platform.**

GradPath AI helps engineering students build technical skills, explore career paths, prepare for placements, and track their learning progress through structured learning roadmaps, interactive quizzes, and career preparation resources.

## 🚀 Live Demo

- **Frontend (Live Website):** https://gradpath-ai-frontend.onrender.com
- **Backend (API Server):** https://gradpath-ai-backend.onrender.com

## ⚙️ Getting Started

### Prerequisites

Install the following:
- Node.js and npm
- Git
- Access to a MongoDB database

### 1. Clone the Repository

```bash
git clone https://github.com/saipravinya144-lab/Gradpath-ai.git
cd Gradpath-ai
```

### 2. Set Up the Backend

```bash
cd backend
npm install
```

Configure the required environment variables in a local `.env` file. Refer to the backend configuration and `package.json` scripts for the required settings and startup command.

Do not commit your `.env` file or credentials to GitHub.

### 3. Set Up the Frontend

Open a second terminal from the project root:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.

Configure the frontend API base URL using the environment variable required by the project. For the deployed frontend, the API base URL is:

```text
https://gradpath-ai-backend.onrender.com
```

## 🌐 Deployment

GradPath AI is deployed using Render.

- **Frontend:** https://gradpath-ai-frontend.onrender.com
- **Backend:** https://gradpath-ai-backend.onrender.com

The frontend communicates with the backend API to support application features such as authentication, student profiles, quizzes, and learning progress.

## 🔒 Security

- Never commit API keys, database credentials, access tokens, or other secrets.
- Store sensitive configuration in environment variables.
- Keep local `.env` files out of version control.
